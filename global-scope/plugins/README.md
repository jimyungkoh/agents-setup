# 전역 플러그인 설치

## 에이전트 지침

이 문서를 전달받은 에이전트는 아래 순서대로 진행한다.

1. 사용자에게 반드시 질문한다:
   "어떤 환경에 설치할까요? pi / Codex CLI / Claude Code / 기타 (복수 선택 가능)"
   - 요청에 환경이 명시되어 있어도 다시 질문하고 답변을 기다린다.
   - 실행 중인 에이전트, 시스템 설정, 이전 대화로 추정하지 않는다.
   - 답변 전에는 설치 명령 실행이나 설정 변경을 하지 않는다.
2. 아래 GitHub 링크 각각의 README를 읽는다.
3. 확인받은 환경에 맞는 공식 설치 절차를 따라 설치하고 검증한다.
   - 절차가 없거나 불명확하면 추측하지 말고 사용자에게 묻는다.
   - 기존 설정을 덮어쓰거나 삭제하기 전에는 동의를 받는다.
4. 설치 결과와 건너뛴 항목을 보고한다.
