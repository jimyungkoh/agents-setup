# 전역 스킬 설치

이 디렉터리의 스킬은 특정 에이전트의 설치 경로나 런타임에 종속되지 않는다. 설치 대상 환경의 공식 스킬 지원 방식을 따른다.

## 에이전트 지침

이 문서를 전달받은 에이전트는 아래 순서대로 진행한다.

1. 사용자에게 반드시 질문한다:
   "어떤 환경에 설치할까요? pi / Codex CLI / Claude Code / 기타 (복수 선택 가능)"
   - 요청에 환경이 명시되어 있어도 다시 질문하고 답변을 기다린다.
   - 실행 중인 에이전트, 시스템 설정, 이전 대화로 추정하지 않는다.
   - 답변 전에는 설치 명령 실행이나 설정 변경을 하지 않는다.
2. 이 저장소의 `global-scope/skills/` 바로 아래에서 `SKILL.md`를 포함한 스킬 디렉터리를 찾아 설치 대상으로 삼는다. 각 `SKILL.md`와 확인받은 환경의 공식 스킬 설치 문서를 읽는다.
   - 전역(사용자) 스코프의 설치 경로, 지원 형식, 로드·호출 방법을 확인한다.
   - 공식 지원이 없거나 절차가 불명확하면 추측하지 말고 사용자에게 묻는다.
3. 확인한 공식 절차에 따라 설치한다.
   - 설치 원본은 이 저장소의 각 스킬 디렉터리다. 출처 링크의 원본으로 대체하지 않는다.
   - 파일 복사 방식이면 `SKILL.md`뿐 아니라 `templates/` 등 동봉 파일을 포함한 디렉터리 전체를 복사하고 상대 경로를 유지한다.
   - 환경별 설정이 필요하면 설치 대상에만 적용하고 이 저장소의 공용 스킬은 변경하지 않는다.
   - 기존 파일·설정을 덮어쓰거나 삭제하기 전에는 동의를 받는다.
4. 설치 파일과 동봉 리소스를 확인하고, 해당 환경의 공식 방법으로 스킬 인식을 검증한다.
   - 재시작이나 사용자 조작이 필요하면 안내한다.
   - 직접 확인하지 못한 인식·호출 결과는 검증 완료로 보고하지 않는다.
5. 환경별 설치 경로, 검증 결과와 건너뛴 항목을 보고한다.

## 설치 대상

설치 대상은 **이 저장소의 `global-scope/skills/` 아래에 있는 모든 스킬**이다. 이 문서가 있는 디렉터리를 기준으로 `*/SKILL.md`를 탐색해 목록을 확인한다.

- `SKILL.md`가 있는 각 디렉터리를 동봉 리소스와 함께 설치한다.
- 이 `README.md` 자체는 설치 대상이 아니다.
- 고정된 목록이나 외부 저장소가 아니라 설치 시점의 로컬 스킬 디렉터리를 기준으로 한다.
